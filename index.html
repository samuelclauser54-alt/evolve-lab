What is happening

  1. Generation 1 is random. Every network starts with random numbers, so almost all of them crash straight away.
  2. Score. Each network gets one number back: how far it got. It is never told what it did wrong.
  3. Select. The top 10% survive unchanged.
  4. Mutate. The rest of the next generation are copies of survivors with small random changes. Repeat.

This is called neuroevolution. Things to try: set mutation to the maximum and watch learning fall apart, or shrink the population to 20 and see how much longer it takes. Every run is different because the starting numbers are random.

What the networks see. Gates: how far the next gap is above or below, own vertical speed, distance to the gate, and the gap after that (4 inputs, 6 hidden neurons, 1 output: flap or not). Driving: 5 distances to the track edge, like laser beams (5 inputs, 6 hidden neurons, 1 output: steering). Each generation gets a new random course, so they cannot memorise one.
